## Code-level scorecard verification boundaries

`src/ucode/critical_path.py` validates **three separate registries**: registered study protocol, selected model manifest, and independently cross-checked PHP/Go pilot status; it crosschecks the older ten-milestone planning ledger and frozen metadata denominator, then derives a DAG and SHA256 provenance receipt. The strict script **fails** if a caller forges a signed oracle, extra policy, runnable model, confirmed treatment effect, altered task cohort, changed model revision, or claimed complete publisher PDF in the current unqualified phase.

It does **not** authenticate the original file publisher, infer scientific completion from source-file existence, score coding performance, use private review notes, or authorize any external task execution. A genuinely qualified future experiment must provide a separate authenticated evidence and study registration path; simply toggling a boolean in this report will never work.
